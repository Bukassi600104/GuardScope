# Install GuardScope

Public Chrome Web Store listing:

https://chromewebstore.google.com/detail/guardscope-email-security/fbjajjiepjmcmkcidfbmjbjmmegokhif

## Installation Steps

1. Open the Chrome Web Store listing above in Google Chrome.
2. Select **Add to Chrome**.
3. Confirm the extension installation prompt.
4. Open Gmail at `https://mail.google.com`.
5. Open a suspicious or test email message.
6. Open the GuardScope side panel or extension entry point.
7. Start a scan only when you want GuardScope to analyze the selected message.
8. Review the advisory risk score, verdict, red flags, green flags, and suggested next steps.

## Launch Code Steps

1. Visit https://guardscope.app/#early-access.
2. Request or use the launch code issued to you.
3. Sign in or create an account when prompted.
4. Activate the code from the GuardScope upgrade flow.

Launch codes provide temporary Pro access during the launch window. They do not require a payment card.

## Privacy Notes

- GuardScope scans only when the user initiates analysis.
- GuardScope does not store email bodies, subjects, sender details, recipients, headers, or extracted email URLs in its databases after producing the analysis response.
- Results are advisory and should be used alongside normal security judgment.
