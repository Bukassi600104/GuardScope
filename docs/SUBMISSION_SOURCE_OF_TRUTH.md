# Submission Source Of Truth

For Chrome Web Store and public launch materials, do not invent or recreate brand, legal, or product assets when an agreed source exists.

## Brand Assets

- Primary logo image: `backend/public/logo.png`
- Favicon / icon geometry: `backend/public/favicon.svg`
- React logo component: `backend/app/components/GuardScopeLogo.tsx`
- Extension icons must be derived from the approved GuardScope mark, not generated from a new concept.

## Legal And Policy Documents

- Privacy policy source: `backend/app/privacy/page.tsx`
- Terms source: `backend/app/terms/page.tsx`
- Security documentation source: `backend/app/security/page.tsx`
- Chrome Web Store submission copy source: `docs/CHROME_WEB_STORE_SUBMISSION.md`

## Rule

If an asset, logo, policy, or listing claim is missing, label the replacement as a draft and ask for approval before treating it as final.
