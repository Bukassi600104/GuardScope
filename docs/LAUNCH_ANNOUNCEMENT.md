## Longer Announcement

GuardScope is now published on the Chrome Web Store.

GuardScope is a Gmail security assistant for user-triggered phishing and email threat analysis. When you choose to scan a suspicious message, GuardScope reviews sender authentication signals, suspicious links, domain risk, threat-intelligence feeds, and social-engineering patterns. It returns an advisory risk score, a clear verdict, evidence-backed red and green flags, and suggested next steps.

Privacy is central to the launch: GuardScope scans only when the user initiates analysis, and GuardScope does not store email bodies, subjects, sender details, recipients, headers, or extracted email URLs in its databases after producing the analysis response.

Install GuardScope from the Chrome Web Store:
https://chromewebstore.google.com/detail/guardscope-email-security/fbjajijepjmcmkcidfbmjbjmmegokhif
